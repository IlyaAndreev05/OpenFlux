# Пример: самостоятельный VPN

Создайте в панели OpenFlux пользователя, документ(ы), пул `standalone`, добавьте пулу документы и выпустите подписку. Приложение регистрирует устройство и получает индивидуальный ключ. Один клиент держит один активный документ из пула; стратегия переключает сессии, а не суммирует полосы.

Схема: OpenFlux Android/Desktop → Yandex Docs transport pool → OpenFlux exit → Internet. Не вставляйте реальные URL документов в git; используйте только локальную конфигурацию.
