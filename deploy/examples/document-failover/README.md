# Пример: два документа с переключением

Создайте пул `sticky` с двумя документами-заглушками из локальной конфигурации и включите оба. Клиент использует один документ для сессии и переключается на резервный при ошибке transport; скорость документов не суммируется. После отказа проверьте новые TCP-соединения, а также перезапуск Control и exit. Не добавляйте настоящие ссылки в пример или commit.
